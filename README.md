# Sumeet Saini

**AI systems engineer building research, forecasting, and agentic developer tools.**

I like software that keeps useful context, makes consequential actions inspectable, and stays fast under the keyboard. My work spans LLM pipelines, probabilistic reasoning, backend systems, developer tooling, creative interfaces, and the infrastructure needed to keep them running.

## What I'm working on

### Elijah · private

Most of my time goes into **Elijah**, a research intelligence and probabilistic forecasting platform. I work across multi-stage LLM research pipelines, Bayesian graph reasoning, API and worker architecture, analyst tooling, testing, and cloud deployment.

The repository is private, but I can discuss the system architecture and non-confidential engineering decisions.
